## 🧩 About

**Delta Force catalog Menu** is a curated list of Delta Force open-source tools:

- **Overlays** — on-screen helpers, layout notes, equipment viewer, loadout switcher
- **Quality-of-Life Helpers** — item catalog, skin manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Loadout Switcher — practice from any saved setup
- Show Zones — visualize map zones and spawn areas
- Replay Notes — record and review match runs
- Playback Speed — adjust demo playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Item Catalog — browse items, camos, charms, effects
- Custom Skin Notes — organize operator cosmetics
- Visibility Notes — improved marker readability

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any layout
- Stance Control Notes — manually switch stance mid-session
- Input Buffer Notes — chain complex maneuvers in the editor
